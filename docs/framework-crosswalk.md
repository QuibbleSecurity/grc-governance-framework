# Framework Crosswalk (Working Notes)

High-level mapping notes between common frameworks, used to accelerate gap assessments when a client needs to satisfy more than one framework simultaneously (e.g., a healthcare SaaS client needing both SOC 2 and HIPAA).

| Control Area | SOC 2 (TSC) | NIST CSF 2.0 | ISO 27001 Annex A | HIPAA |
|---|---|---|---|---|
| Access Control | CC6.1, CC6.2, CC6.3 | PR.AC | A.9 | 164.312(a) |
| Incident Response | CC7.2, CC7.3 | RS.RP, RS.CO | A.16 | 164.308(a)(6) |
| Risk Assessment | CC3.1, CC3.2 | ID.RA | A.6, A.8 | 164.308(a)(1) |
| Asset Management | CC6.1 | ID.AM | A.5, A.8 | 164.310 |
| Vendor/Third-Party Risk | CC9.2 | ID.SC | A.15 | 164.308(b) |
| Training & Awareness | CC1.4 | PR.AT | A.6.3 | 164.308(a)(5) |

This crosswalk is a starting reference, not a certified mapping — always validate against the current published framework text and, where relevant, an auditor's interpretation.
